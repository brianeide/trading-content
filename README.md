# Trading Content

Welcome to my trading content library, an aggregator and archive for all resources on quantitative trading and investing. This repository is a constant work in progress. There may be errors and poorly labeled links. Contributions are welcome!

# People

This repository began as an archive of Benn Eifert's Twitter threads. It has since expanded to archive the knowledge in content shared by many other great practitioners, including podcast appearances. I use https://twitter-thread.com to save interesting Twitter posts, but my goal is to fully archive these posts in markdown files hosted in this repository.
